# Frontend Design Skill

Generate distinctive, production-grade frontend interfaces with high design quality.

## Purpose
Create interfaces that avoid generic AI aesthetics. Every component should feel intentionally designed with real working code and exceptional attention to aesthetic details and creative choices.

## Design Thinking Framework

Before writing any code:
1. **Understand the purpose** - What does this interface need to accomplish?
2. **Select a bold aesthetic direction** - Choose from: brutalist, maximalist, retro-futuristic, luxury minimalist, glassmorphism, neubrutalism, dark mode premium, etc.
3. **Note technical constraints** - Framework, existing design system, responsive needs
4. **Identify the unforgettable element** - What makes this stand out?

## Key Principles

- **Production-grade** - Functional, accessible, responsive code
- **Visually striking** - Bold choices that create memorable experiences
- **Cohesive vision** - Every element serves the aesthetic
- **Meticulous refinement** - Pixel-perfect attention to detail

## Aesthetic Focus Areas

### Typography
Choose fonts that are beautiful, unique, and interesting. Avoid generic fonts like Arial and Inter. Consider:
- Font pairing with contrast (serif + sans-serif)
- Variable font weights for hierarchy
- Letter-spacing and line-height fine-tuning
- Custom font features (ligatures, alternates)

### Color & Theme
Build cohesive palettes:
- Dominant color with sharp accents
- Meaningful use of color for hierarchy and state
- Dark/light mode with distinct personalities
- Gradient usage that enhances, not decorates

### Motion & Animation
CSS animations that add polish:
- Micro-interactions on hover and focus states
- Smooth transitions between states (200-300ms)
- Scroll-triggered reveals
- Loading state animations
- Spring physics for natural feel

### Spatial Composition
- Asymmetric layouts that create visual interest
- Generous whitespace as a design element
- Grid systems with purposeful breaks
- Responsive scaling that maintains personality

### Visual Details
- Subtle gradients and shadows for depth
- Border treatments (radius, width, style)
- Background textures and patterns where appropriate
- Custom SVG icons and illustrations
- Backdrop blur and glassmorphism effects

## Critical Warnings

AVOID generic AI-generated aesthetics:
- NO overused Inter/sans-serif everywhere
- NO cliche purple/blue gradients
- NO predictable card-grid layouts
- NO cookie-cutter designs lacking context
- NO default shadcn/Tailwind without customization
- NO identical-looking components across pages

## Implementation

Match complexity to aesthetic vision:
- Simple layouts = bold typography + color
- Complex dashboards = refined spacing + subtle animation
- Marketing pages = dramatic visuals + scroll interactions
- Admin panels = clean hierarchy + micro-interactions

Always be bold. Always be context-specific. Always create something memorable.
